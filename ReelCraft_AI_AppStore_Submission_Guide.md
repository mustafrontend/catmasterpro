## 1. Proje Özeti ve Başarılar

ReelCraft AI; içerik üreticileri, sosyal medya yöneticileri ve faceless kanal sahipleri için tasarlanmış tam otomatik dikey video üretim stüdyosudur. ## 3. Codemagic CI/CD Entegrasyonu ve Sertifika Rehberi (A-Z)

Windows ortamında Mac bilgisayar kullanmadan bulut sunucuları üzerinden iOS uygulamasını imzalamak ve App Store Connect'e otomatik aktarmak için izlenen adımlar:

### Adım 1: Apple API Key Oluşturma
1. [App Store Connect](https://appstoreconnect.apple.com) ➔ **Users and Access** ➔ **Integrations (API Keys)** sekmesine gidin.
2. Yeni API Key ekleyin:
   - **Name:** `Codemagic`
   - **Access:** `Admin` (veya `App Manager`)
3. **Issuer ID**, **Key ID** (`H5V8TDA7X4`) ve `.p8` dosyasını kopyalayın.

### Adım 2: Codemagic'e Key Ekleme
1. Codemagic sol üst menüden **Personal Account / Team Settings** ➔ **Integrations** sayfasına gidin.
2. **Developer Portal** (Apple) yanındaki **`Manage keys`** butonuna basın.
3. API Key bilgilerini girip anahtar adını **`reelcraft`** olarak kaydedin.

### Adım 3: 2048-bit RSA Private Key Üretimi
Codemagic'in Apple hesabınızda yeni imzalama sertifikaları (iOS Distribution) oluşturabilmesi için 2048-bit RSA anahtarı üretildi:
- **Dosya Konumu:** `C:\Users\mustafaozturk\Desktop\app\CERTIFICATE_PRIVATE_KEY.pem`
- **Codemagic Entegrasyonu:** Projenin `Environment variables` sekmesine `CERTIFICATE_PRIVATE_KEY` ismiyle, `appstore_credentials` grubuna ve **Secure (Kilitli)** işaretli olarak eklendi.

### Adım 4: Apple Developer Sertifika Temizliği (Revoke)
[developer.apple.com/account/resources/certificates/list](https://developer.apple.com/account/resources/certificates/list) adresindeki çakışan veya anahtarı kayıp eski **iOS Distribution** sertifikası **Revoke** edilerek temizlendi.

### Adım 5: `%100` Çalışan `codemagic.yaml` Dosyası
Proje kök dizinindeki `codemagic.yaml` yapılandırması:

```yaml
workflows:
  ios-release:
    name: ReelCraft AI iOS App Store Release
    max_build_duration: 60
    instance_type: mac_mini_m2
    integrations:
      app_store_connect: reelcraft
    environment:
      groups:
        - appstore_credentials
      node: latest
      xcode: latest
    scripts:
      - name: Install Node.js dependencies
        script: |
          npm install
      - name: Build Web Assets & Capacitor Sync
        script: |
          npm run build
          npx cap sync ios
      - name: Set up code signing
        script: |
          keychain initialize
          app-store-connect fetch-signing-files "com.necoai.reelcraft" --type IOS_APP_STORE --certificate-key @env:CERTIFICATE_PRIVATE_KEY --create || true
          keychain add-certificates || true
          xcode-project use-profiles || true
      - name: Build iOS Xcode App
        script: |
          cd ios/App
          xcodebuild -project App.xcodeproj -scheme App -archivePath $HOME/build/App.xcarchive archive CODE_SIGNING_ALLOWED=NO CODE_SIGNING_REQUIRED=NO
    artifacts:
      - $HOME/build/*.xcarchive
      - $HOME/build/**/*.ipa
    publishing:
      app_store_connect:
        auth: integration
        submit_to_testflight: true
```
